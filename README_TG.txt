CINEMATICKET — Дастури насб

Талабот: XAMPP (Apache + MySQL), браузер.

1. Папкаи CinemaTicket-ро ба C:\xampp\htdocs\ нусха кунед.
2. XAMPP Control Panel-ро кушоед.
3. Apache ва MySQL-ро Start кунед.
4. Дар браузер http://localhost/phpmyadmin кушоед.
5. Ҷадвали Import-ро интихоб кунед.
6. Файли database/cinema_db.sql-ро интихоб карда Import-ро пахш кунед.
7. Сомонаро кушоед: http://localhost/CinemaTicket/

Эзоҳҳои муҳим:
- Ин версия барои омӯзиш ва кори лоиҳавӣ мебошад.
- Пардохт дар ин версия тақлидӣ аст: баъди тасдиқи фармоиш чипта сабт мешавад.
- QR дар чипта рамзи намоишӣ аст, на QR-и сканшавандаи воқеӣ.
- Пеш аз истифодаи воқеӣ бояд HTTPS, сиёсати пардохт, санҷиши чипта ва ҳифзи иловагӣ илова шаванд.
- Агар MySQL-и шумо пароли root дошта бошад, онро дар config/database.php нав кунед.
