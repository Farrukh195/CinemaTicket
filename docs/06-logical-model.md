# Модели мантиқии базаи маълумот: CinemaTicket

## 1. Муқаддима

CinemaTicket системаи электронӣ барои тамошои филмҳо ва хариди билетҳои кинотеатр мебошад.

Мақсади система автоматӣ намудани раванди интихоби филм, дидани вақти намоиш, интихоби ҷойи нишаст ва хариди билет мебошад.

Дар базаи маълумот маълумоти истифодабарандагон, филмҳо, жанрҳо, толорҳо, ҷойҳои нишаст, намоиши филмҳо ва билетҳо нигоҳ дошта мешавад.

## 3. Нормализатсияи базаи маълумот

### 3.1. Шакли якуми нормалӣ (1НФ)

Шартҳои 1НФ:
- Ҳар як чашмаки ҷадвал бояд танҳо як қимат дошта бошад.
- Дар ҳар як сатр маълумоти ягона нигоҳ дошта шавад.
- Гурӯҳҳои такроршавандаи маълумот вуҷуд надошта бошанд.

Камбудиҳо:
- Маълумоти истифодабарандагон, филмҳо ва билетҳо дар як ҷадвал ҷойгир шудаанд.
- Баъзе маълумотҳо такроран истифода мешаванд.

Ҳалли масъала:
- Маълумот ба майдонҳои алоҳида ҷудо карда мешавад.
- Барои ҳар як сабт калиди ягона истифода мешавад.
- Маълумоти гуногун ба ҷадвалҳои алоҳида тақсим карда мешавад.

### 3.2. Шакли дуюми нормалӣ (2НФ)

Шартҳои 2НФ:
- Ҷадвал бояд ба 1НФ мувофиқ бошад.
- Ҳар як атрибути ғайрикалидӣ бояд пурра аз калиди ибтидоӣ вобаста бошад.

Камбудиҳо:
- Маълумоти филм аз филм вобаста аст, на аз билет.
- Маълумоти истифодабаранда ба худи истифодабаранда тааллуқ дорад.
- Маълумоти толор ва ҷойҳои нишаст бояд алоҳида нигоҳ дошта шавад.

Ҳалли масъала:
- Барои ҳар як ҷадвал калиди ибтидоии одии id истифода мешавад.
- Маълумоти истифодабарандагон дар users нигоҳ дошта мешавад.
- Маълумоти филмҳо дар films нигоҳ дошта мешавад.
- Маълумоти толорҳо дар halls нигоҳ дошта мешавад.
- Маълумоти ҷойҳо дар seats нигоҳ дошта мешавад.
- Маълумоти намоишҳо дар screenings нигоҳ дошта мешавад.
- Маълумоти билетҳо дар tickets нигоҳ дошта мешавад.

### 3.3. Шакли сеюми нормалӣ (3НФ)

Шартҳои 3НФ:
- Ҷадвал бояд ба 2НФ мувофиқ бошад.
- Байни атрибутҳои ғайрикалидӣ вобастагии транзитивӣ набошад.

Вобастагиҳои транзитивӣ:

| Вобастагӣ | Ҳалли масъала |
|---|---|
| Филм → жанр_id → номи жанр | Ҷадвали genres сохта мешавад |
| Истифодабаранда → role_id → номи нақш | Ҷадвали roles сохта мешавад |
| Толор → маълумоти ҷойҳо | Ҷадвали seats сохта мешавад |

Натиҷа:

Баъд аз ҷудо намудани маълумот ба ҷадвалҳои алоҳида базаи маълумот ба шакли сеюми нормалӣ (3НФ) оварда мешавад.

## 4. Рӯйхати ҷадвалҳо

Дар базаи маълумоти CinemaTicket ҷадвалҳои зерин истифода мешаванд:

1. users — истифодабарандагон.
2. roles — нақшҳои истифодабарандагон.
3. films — маълумоти филмҳо.
4. genres — жанрҳои филмҳо.
5. halls — толорҳои кинотеатр.
6. seats — ҷойҳои нишаст.
7. screenings — намоиши филмҳо.
8. tickets — билетҳои харидашуда.

## 6. Робитаи байни ҷадвалҳо

| № | Робитаи ҷадвалҳо | Навъи робита | Калиди хориҷӣ |
|---|---|---|---|
| 1 | roles — users | 1:N | users.role_id |
| 2 | films — film_genres | 1:N | film_genres.film_id |
| 3 | genres — film_genres | 1:N | film_genres.genre_id |
| 4 | halls — seats | 1:N | seats.hall_id |
| 5 | films — screenings | 1:N | screenings.film_id |
| 6 | halls — screenings | 1:N | screenings.hall_id |
| 7 | users — tickets | 1:N | tickets.user_id |
| 8 | screenings — tickets | 1:N | tickets.screening_id |
| 9 | seats — tickets | 1:N | tickets.seat_id |

### Робитаи M:N

Байни ҷадвалҳои films ва genres робитаи бисёр-ба-бисёр (M:N) вуҷуд дорад.

Як филм метавонад якчанд жанр дошта бошад ва як жанр метавонад ба якчанд филм тааллуқ дошта бошад.

Барои ташкил кардани ин робита ҷадвали film_genres истифода мешавад.
## 7. Маҳдудиятҳои якпорчагии маълумот

### 7.1. Маҳдудиятҳои UNIQUE

Барои пешгирии маълумоти такрорӣ маҳдудиятҳои зерин истифода мешаванд:

1. users.email — почтаи электронии истифодабаранда бояд такрор нашавад.
2. roles.name — номи нақш бояд ягона бошад.
3. genres.name — номи жанр бояд ягона бошад.

### 7.2. Маҳдудияти CHECK

- films.duration > 0 — давомнокии филм бояд аз сифр зиёд бошад.
- halls.capacity > 0 — шумораи ҷойҳои толор бояд аз сифр зиёд бошад.
- screenings.price >= 0 — нархи билет набояд манфӣ бошад.

### 7.3. Қоидаҳои ON DELETE

- roles → users: ON DELETE RESTRICT.
- films → film_genres: ON DELETE CASCADE.
- genres → film_genres: ON DELETE CASCADE.
- halls → seats: ON DELETE RESTRICT.
- films → screenings: ON DELETE RESTRICT.
- halls → screenings: ON DELETE RESTRICT.
- users → tickets: ON DELETE RESTRICT.
- screenings → tickets: ON DELETE RESTRICT.
- seats → tickets: ON DELETE RESTRICT.

Ин маҳдудиятҳо якпорчагӣ ва дурустии маълумоти базаи маълумотро таъмин мекунанд.
