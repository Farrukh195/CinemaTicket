# Супориши мухтасари техникӣ: CinemaTicket

## 1. Мақсади система

CinemaTicket — системаи иттилоотӣ барои фурӯши чиптаҳои кинотеатр мебошад. Система ба истифодабарандагон имконият медиҳад, ки филмҳоро тамошо кунанд, вақти намоиши филмро интихоб намоянд ва чиптаҳоро онлайн харидорӣ кунанд.

## 2. Истифодабарандагони система

- **Admin** — маъмури система.
- **Customer** — харидори чипта.
- **Cashier** — хазинадори кинотеатр.
- **Guest** — меҳмони система.

## 4. Ҳикояҳои истифодабарандагон (User Stories)

**US-01 (ФТ-02, ФТ-03).** Ҳамчун меҳмон (Guest), ман мехоҳам рӯйхати филмҳоро бинам, то филми дилхоҳамро интихоб кунам.

- Дода шудааст: меҳмон ба саҳифаи асосӣ ворид шудааст. Вақте ки: рӯйхати филмҳоро мекушояд. Он гоҳ: ҳамаи филмҳои дастрас нишон дода мешаванд.
- Дода шудааст: меҳмон рӯйхати филмҳоро мебинад. Вақте ки: як филмро интихоб мекунад. Он гоҳ: ном, жанр, тавсиф ва расми филм нишон дода мешаванд.

**US-02 (ФТ-01, ФТ-09).** Ҳамчун харидор (Customer), ман мехоҳам ба система ворид шуда, чипта харам, то ба тамошои филм равам.

- Дода шудааст: харидор ба система ворид шудааст. Вақте ки: филм, сана ва вақтро интихоб мекунад. Он гоҳ: ҷойҳои дастрас нишон дода мешаванд.
- Дода шудааст: харидор ҷойи озодро интихоб кардааст. Вақте ки: фармоишро тасдиқ мекунад. Он гоҳ: чипта дар система сабт мешавад.

**US-03 (ФТ-04, ФТ-05).** Ҳамчун маъмур (Admin), ман мехоҳам филмҳои навро илова ва таҳрир кунам, то рӯйхати филмҳо нав бошад.

- Дода шудааст: маъмур ба система ворид шудааст. Вақте ки: маълумоти филми навро илова мекунад. Он гоҳ: филм дар рӯйхати филмҳо пайдо мешавад.
- Дода шудааст: филм дар система мавҷуд аст. Вақте ки: маъмур маълумоти онро тағйир медиҳад. Он гоҳ: маълумоти нав нигоҳ дошта мешавад.

**US-04 (ФТ-10).** Ҳамчун хазинадор (Cashier), ман мехоҳам рақами чиптаро санҷам, то ҳақиқӣ будани онро муайян кунам.

- Дода шудааст: чипта дар система мавҷуд аст. Вақте ки: хазинадор рақами онро ворид мекунад. Он гоҳ: маълумоти чипта нишон дода мешавад.
- Дода шудааст: чипта аллакай истифода шудааст. Вақте ки: хазинадор онро такроран месанҷад. Он гоҳ: система огоҳӣ медиҳад.

**US-05 (ФТ-11, ФТ-12).** Ҳамчун харидор (Customer), ман мехоҳам филмҳоро ҷустуҷӯ карда, таърихи хариди худро бинам, то маълумоти заруриро зуд пайдо кунам.

- Дода шудааст: харидор дар саҳифаи филмҳо қарор дорад. Вақте ки: номи филмро дар ҷустуҷӯ менависад. Он гоҳ: филмҳои мувофиқ нишон дода мешаванд.
- Дода шудааст: харидор қаблан чипта харидааст. Вақте ки: таърихи харидро мекушояд. Он гоҳ: рӯйхати харидҳои пешина нишон дода мешавад.

## 6. MVP — версияи аввалини система

Дар версияи аввалини CinemaTicket вазифаҳои асосии зерин амалӣ карда мешаванд:

1. Бақайдгирӣ ва воридшавии истифодабарандагон (ФТ-01).
2. Намоиши рӯйхати филмҳо (ФТ-02).
3. Намоиши маълумоти пурраи филм (ФТ-03).
4. Илова кардани филмҳои нав аз тарафи маъмур (ФТ-04).
5. Таҳрир ва нест кардани филмҳо (ФТ-05).
6. Идоракунии ҷадвали намоиши филмҳо (ФТ-06).
7. Интихоби сана ва вақти намоиши филм (ФТ-07).
8. Интихоби ҷой дар толори кинотеатр (ФТ-08).
9. Харидани чипта (ФТ-09).

Ин вазифаҳо барои оғози кори система заруранд.
## 7. Вне границ проекта

Дар версияи аввали CinemaTicket вазифаҳои зерин ба система дохил намешаванд:

1. Тамошои филмҳо тавассути интернет (онлайн).
2. Пахши мустақими филмҳо.
3. Барномаи алоҳида барои Android ва iOS.
4. Пардохт тавассути кортҳои бонкӣ ва ҳамёнҳои электронӣ.
5. Системаи бонусҳо ва тахфифҳои махсус.
6. Интихоби забонҳои гуногун дар система.

Ин имкониятҳо метавонанд дар версияҳои ояндаи система илова карда шаванд.
