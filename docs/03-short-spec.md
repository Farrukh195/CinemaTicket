# Талаботи мухтасари техникӣ: CinemaTicket

## 1. Мақсади система

Системаи CinemaTicket барои автоматӣ намудани раванди фурӯши чиптаҳои кинотеатр пешбинӣ шудааст. Система ба мизоҷон имкон медиҳад, ки рӯйхати филмҳоро бинанд, филми дилхоҳро интихоб кунанд, вақти намоиш ва ҷойи нишастро муайян намуда, чиптаро онлайн харанд.

Маъмур метавонад филмҳо, сеансҳо, чиптаҳо ва истифодабарандагонро идора намояд.

## 2. Истифодабарандагони система

- client — мизоҷ;
- admin — маъмур.

## 4. Ҳикояҳои истифодабарандагон (User Stories)

### US-01 (ФТ-01). Бақайдгирӣ

Ҳамчун мизоҷ, ман мехоҳам дар система бақайд гирам, то тавонам чиптаҳои кинотеатрро харам.

- Дода шудааст: мизоҷ саҳифаи бақайдгириро мекушояд. Вақте ки маълумоти дурустро ворид мекунад, система бояд ҳисоб кушояд.
- Дода шудааст: рақами телефон аллакай сабт шудааст. Вақте ки мизоҷ дубора бақайд мегирад, система бояд хатогиро нишон диҳад.

### US-02 (ФТ-03). Дидани филмҳо

Ҳамчун мизоҷ, ман мехоҳам рӯйхати филмҳоро бинам, то филми дилхоҳамро интихоб кунам.

- Дода шудааст: мизоҷ ба саҳифаи филмҳо ворид шудааст. Система бояд рӯйхати филмҳоро нишон диҳад.
- Дода шудааст: филмҳо мавҷуд нестанд. Система бояд паёми мувофиқ нишон диҳад.

### US-03 (ФТ-06). Интихоби ҷой

Ҳамчун мизоҷ, ман мехоҳам ҷойи нишасти холиро интихоб кунам, то дар кинотеатр бароҳат нишинам.

- Дода шудааст: мизоҷ сеансро интихоб кардааст. Система бояд ҷойҳои холиро нишон диҳад.
- Дода шудааст: ҷой аллакай банд аст. Система бояд имконияти интихоби онро маҳдуд кунад.

### US-04 (ФТ-08). Харидани чипта

Ҳамчун мизоҷ, ман мехоҳам чиптаро харам, то ба тамошои филм равам.

- Дода шудааст: мизоҷ филм, сеанс ва ҷойро интихоб кардааст. Вақте ки харидро тасдиқ мекунад, система бояд чиптаро сабт намояд.
- Дода шудааст: пардохт номуваффақ аст. Система бояд паёми хатогиро нишон диҳад.

### US-05 (ФТ-11). Илова кардани филм

Ҳамчун маъмур, ман мехоҳам филмҳои нав илова кунам, то мизоҷон онҳоро бинанд.

- Дода шудааст: маъмур ба система ворид шудааст. Вақте ки маълумоти филмро илова мекунад, система бояд онро нигоҳ дорад.
- Дода шудааст: маълумоти ҳатмӣ пур карда нашудааст. Система бояд хатогиро нишон диҳад.

## 6. MVP — Нусхаи аввалини система

Ба нусхаи аввалини система вазифаҳои зерин дохил мешаванд:

1. Бақайдгирӣ ва воридшавӣ.
2. Дидани рӯйхати филмҳо.
3. Дидани маълумоти филмҳо.
4. Интихоби филм ва сеанс.
5. Интихоби ҷойи нишаст.
6. Ҳисоб кардани нархи чипта.
7. Харидани чипта.
8. Нигоҳ доштани маълумоти чипта.
9. Дидани чиптаҳои харидашуда.
10. Идоракунии филмҳо аз тарафи маъмур.
11. Идоракунии сеансҳо.

## 7. Корҳое, ки ба лоиҳа дохил намешаванд

- Хариди чипта тавассути барномаи мобилӣ.
- Системаи мураккаби бонусҳо.
- Пайвастшавӣ бо кинотеатрҳои дигар.
- Истифодаи зеҳни сунъӣ барои тавсия додани филмҳо.
- Системаи мураккаби тахфифҳо.
