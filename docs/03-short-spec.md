
# Талаботи мухтасари техникӣ: taxi-service

## 1. Мақсади система

Системаи фармоиши таксӣ барои автоматӣ намудани раванди фармоиши мошин, ҷустуҷӯи ронанда ва идоракунии фармоишҳо пешбинӣ шудааст. Система ба мусофирон имкон медиҳад, ки ба осонӣ таксӣ фармоиш диҳанд ва ронандагон фармоишҳоро қабул карда, сафарро иҷро намоянд.

## 2. Истифодабарандагони система

- passenger — мусофир;
- driver — ронанда;
- admin — маъмур.

## 4. Ҳикояҳои истифодабарандагон (User Stories)

### US-01 (ФТ-01). Бақайдгирӣ

Ҳамчун мусофир, ман мехоҳам дар система бақайд гирам, то тавонам таксӣ фармоиш диҳам.

- Дода шудааст: истифодабаранда саҳифаи бақайдгириро кушодааст. Вақте ки маълумоти дурустро ворид мекунад, система бояд ҳисоб кушояд.
- Дода шудааст: рақами телефон аллакай сабт шудааст. Вақте ки истифодабаранда дубора бақайд мегирад, система бояд хатогиро нишон диҳад.

### US-02 (ФТ-03). Фармоиши таксӣ

Ҳамчун мусофир, ман мехоҳам суроғаи рафтан ва расиданро ворид кунам, то таксӣ фармоиш диҳам.

- Дода шудааст: мусофир ба система ворид шудааст. Вақте ки суроғаҳоро ворид карда, тугмаи «Фармоиш додан»-ро пахш мекунад, фармоиш бояд сохта шавад.
- Дода шудааст: суроғаи расидан холӣ аст. Вақте ки мусофир фармоиш медиҳад, система бояд хатогиро нишон диҳад.

### US-03 (ФТ-06). Қабули фармоиш

Ҳамчун ронанда, ман мехоҳам фармоишҳоро қабул кунам, то мусофиронро ба ҷойи лозима расонам.

- Дода шудааст: ронанда ба система ворид шудааст. Вақте ки фармоишро қабул мекунад, фармоиш бояд ба ӯ вобаста карда шавад.
- Дода шудааст: фармоишро ронандаи дигар қабул кардааст. Вақте ки ронанда кӯшиш мекунад онро қабул кунад, система бояд паёми хатогӣ нишон диҳад.

### US-04 (ФТ-08). Анҷом додани сафар

Ҳамчун ронанда, ман мехоҳам сафарро анҷом диҳам, то фармоиш баста шавад.

- Дода шудааст: сафар оғоз шудааст. Вақте ки ронанда тугмаи «Анҷом додан»-ро пахш мекунад, ҳолати фармоиш бояд completed шавад.
- Дода шудааст: сафар ҳанӯз оғоз нашудааст. Вақте ки ронанда мехоҳад онро анҷом диҳад, система бояд ин амалро манъ кунад.

### US-05 (ФТ-10). Идоракунии истифодабарандагон

Ҳамчун маъмур, ман мехоҳам мусофирон ва ронандагонро идора кунам, то кори системаро назорат намоям.

- Дода шудааст: маъмур ба система ворид шудааст. Вақте ки рӯйхати истифодабарандагонро мекушояд, система бояд мусофирон ва ронандагонро нишон диҳад.
- Дода шудааст: истифодабаранда дар система мавҷуд аст. Вақте ки маъмур ӯро маҳкам мекунад, ҳолати ӯ бояд blocked шавад.

## 6. MVP — Нусхаи аввалини система

Ба нусхаи аввалини система вазифаҳои зерин дохил мешаванд:

1. Бақайдгирӣ ва воридшавӣ.
2. Дидан ва таҳрир кардани маълумоти шахсӣ.
3. Сохтани фармоиши таксӣ.
4. Ҳисоб кардани нархи сафар.
5. Ҷустуҷӯи ронандаи озод.
6. Қабул ва рад кардани фармоиш.
7. Бекор кардани фармоиш.
8. Анҷом додани сафар.
9. Идора кардани истифодабарандагон.

## 7. Корҳое, ки ба лоиҳа дохил намешаванд

- Пардохти онлайн тавассути корти бонкӣ.
- Пайвастшавӣ бо дигар хизматрасониҳои таксӣ.
- Ёрдамчии овозӣ.
- Истифодаи зеҳни сунъӣ барои тақсим кардани фармоишҳо.
